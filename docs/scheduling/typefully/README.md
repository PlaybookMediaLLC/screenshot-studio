# Typefully functional reverse engineering

Inspected 13 October 2026 in the signed-in Typefully web app. These documents describe visible product behavior. They are not recovered source code, database schemas, or private API contracts.

Each document labels its evidence. **LIVE** or **Observed** means the behavior was seen in the app. **DOC** means official documentation. **PROPOSED** means an implementation recommendation.
