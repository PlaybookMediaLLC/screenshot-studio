# RFC renumbering — 2026-10-24

All 52 RFCs now use priority numbers 001–052. The [RFC index](README.md) is
the delivery plan; [catalog.json](catalog.json) is the machine-readable mapping.
The previous-ID column refers to the numbering before this change. Repository
links, prose, source comments and verification rules use the new IDs. External
issues, old PR descriptions and historical commits may still use previous IDs;
use this table to resolve them.

Numbers order new investment. Existing access-control and reliability obligations
remain mandatory regardless of where a foundation appears in the list.
