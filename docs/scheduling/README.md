# Scheduling research

Functional reverse engineering of two social scheduling products, inspected 13 October 2026. Use it as input when you design scheduling, publishing, and post management for Shots.

| Product | Index | Features |
|---|---|---|
| Post Bridge | [post-bridge/](post-bridge/README.md) | [Composer](post-bridge/composer/), [Content Studio](post-bridge/content-studio/), [Bulk Tools](post-bridge/bulk-tools/), [Calendar, post lists, and Connections](post-bridge/post-management/) |
| Typefully | [typefully/](typefully/README.md) | [Write](typefully/write/), [Plan and Analyze](typefully/plan-and-analyze/), [Social sets and teams](typefully/social-sets-and-teams/), [Settings](typefully/settings/), [Brand kit](typefully/brand-kit/) |

Each feature folder holds the analysis, its observed contracts and verification matrices, and the screenshots and sample media it cites.

No post was published or scheduled during the inspections. Each document states what the inspection changed and what it did not test.
